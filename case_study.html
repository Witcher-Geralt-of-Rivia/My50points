1. Executive Summary

50points is a tournament-based horse racing prediction platform powered by official, real-time results from United States racetracks. The core mechanic establishes that 1 ticket = 1 tournament = the last 7 races of the racetrack. Unlike traditional race-by-race gambling, scoring is deterministic and directly tied to official racetrack payout dividends (Win payoff, base $2.00) multiplied by chosen strategy weights (Full Point, Dual Point, or Smart Point).

Following stakeholder directives, this technical review was conducted in a non-destructive audit mode: the baseline was verified in main, dependencies and servers were built and executed in an isolated local environment, and zero architectural migrations or database modifications were made. The goal is to audit current runtime health, pinpoint reusable logic, and prepare for the upcoming client Figma overhaul.

3. Core Game Mechanics & Scoring Strategies

Full Point (50)

Selection: 1 Horse

Formula: Round(50 × Dividendo)

Maximum risk, maximum reward. Points awarded only if chosen horse wins.

Dual Point (25 + 25)

Selection: 2 Horses

Formula: Round(25 × Dividendo)

Balanced strategy across two runners. Win payoff applied to the winning slot.

Smart Point (30 / 15 / 5)

Selection: 3 Horses

Formula: Round(Base_Slot × Dividendo)

Strategic distribution. Scratched picks transfer to post-time favorite.

4. Runtime Verification & Audit Findings

Audit Confirmation: 100% Non-Destructive Execution

Tests were run using local virtual environments and local ports (Backend: 8000, Frontend: 3000). The remote Git repository working tree remains clean and untouched.

Backend Service Verification
  • Server Lifespan & Seeding: Executed python run.py --port 8000. Initialized SQLite, applied missing columns, and seeded sample US racetracks.
  • Health & Endpoints: GET /health returned 200 OK. GET /api/tournaments returned active tournaments and races with correct timezone conversions.
  • Authentication & Guest: Tested POST /api/auth/guest. Generated unique guest credentials with 12h expiration JWT and guest token (50P-814495).
  • Scoring Simulation: Verified simulate_results.py. Confirmed dividend calculations, leaderboard deltas, and streak updates.
Frontend Web App Verification
  • Build & Server: Executed Next.js 14 dev server via scripts/next-cli.mjs. Resolved Windows path casing normalization automatically.
  • Route Testing (200 OK): Validated /, /tournaments, /tournament/[id], /leaderboard, /how-to-play, /login, /register, /profile.
  • Routing Structure: Confirmed tournament detail is mounted on /tournament/[id] (singular), while the index is /tournaments.
  • Linting: ESLint error found in ProfileTicketHistoryPanel.jsx (unescaped quotes), currently bypassed via ignoreDuringBuilds.
